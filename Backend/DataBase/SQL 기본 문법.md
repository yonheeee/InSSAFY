
## SQL 구문의 종류

| 구분 | SQL구문 | 설명 |
| --- | --- | --- |
| DML | INSERT | 레코드 삽입 |
| DML | UPDATE | 레코드 수정 |
| DML | DELETE | 레코드 삭제 |
| DML | SELECT | 레코드 조회, DQL |
| DDL | CREATE | 데이터베이스 객체 생성 |
| DDL | ALTER | 데이터베이스 객체 수정 |
| DDL | DROP | 데이터베이스 객체 삭제 |
| DDL | RENAME | 데이터베이스 객체 이름 수정 |
| TCL | COMMIT | 변경된 내용이 있다면 적용하며 트랜잭션 종료 |
| TCL | ROLLBACK | 변경된 내용이 있어도 적용하지 않으며 트랜잭션 종료 |
| TCL | SAVEPOINT | 트랜잭션의 일부만 롤백할 수 있는 저장점 생성 |
| DCL | GRANT | 데이터베이스와 객체들에 대한 다양한 권한 부여 |
| DCL | REVOKE | 데이터베이스와 객체들에 대해 부여된 권한 회수 |

### Select 기본 구문

```jsx
SELECT * | {[DISTINCT] {{컬럼명 | 표현식} {[AS] [별칭], ...}}
FROM   테이블명
WHERE  조건식 [ {AND | OR }, 조건식]
GROUP BY 컬럼명 | 표현식 | [컬럼명 | 표현식, ..]
HAVING 조건
ORDER BY 기준1 [ASC | DESC] [, 기준2 [ASC | DESC]]
```

- SELECT
    - 조회하려는 컬럼명 또는 표현식 나열
    - 별칭 사용
- FROM
    - 조회하려는 데이터가 저장된 테이블
- WHERE
    - 결과 집합을 필터링
    - 테이블에 저장된 데이터 원하는 데이터만 검색
- GROUP BY
    - 결과 집합의 하위 데이터 그룹을 만듦
    - GROUP BY 절에 기술한 컬럼이나 표현식을 기준으로 결과 집합 전체 행을 그룹 별로 나눔
    - SELETE절의 모든 요소는 GROUP BY 절의 표현식, 집계 함수를 포함하는 표현식 또는 상수만 가능
- HAVING절
    - GROUP BY 절에 의해 생성된 그룹을 대상으로 조건을 적용하여 그룹을 필터링하기 위해 사용
- ORDER BY
    - SELECT 구문 실행 결과를 특정 컬럼 값 기준으로 정렬할 때 사용
    - 정렬 조건
        - ASC : 오름차순(기본값)
        - DESC : 내림차순
  

### 비교 연산자

| 연산자 | 설명 |
| --- | --- |
| = | 같다 |
| !=, <> | 같지 않다 |
| <, <=, >, >= | 작다, 작거나 같다, 크다, 크거나 같다 |
| IS NULL | NULL인지 비교 |
| BETWEEN a AND b | a 이상 b 이하 범위 비교 (경계값 포함) |
| IN (value1, value2, ...) | 목록 안에 일치하는 값이 있는지 비교 |
| LIKE | 특정 패턴을 만족하는지 비교 |
| % | 0개 이상의 임의의 문자 |
| _ | 1개의 임의의 문자 |

### 논리 연산자

| 연산자 | 설명 |
| --- | --- |
| AND, && | 논리 곱 |
| OR, || | 논리 합 |
| XOR | 배타적 논리 합 (두 논리식의 결과가 서로 다를 때만 참) |
| NOT, ! | 논리 부정 |

### 비트 연산자

| 연산자 | 설명 |
| --- | --- |
| & | 두 비트가 모두 1이면 1 반환 (AND 연산) |
| | | 두 비트 중 하나라도 1이면 1 반환 (OR 연산) |
| ^ | 두 비트가 서로 다르면 1 반환 (XOR 연산) |
| ~ | 비트를 반전 (1 → 0, 0 → 1) (NOT 연산) |
| << | 지정한 수만큼 비트를 왼쪽으로 이동 (left shift) |
| >> | 부호를 유지하면서 지정한 수만큼 비트를 오른쪽으로 이동 (right shift) |

## 집계함수
- 결과를 만족하는 전체 행을 하나 이상의 컬럼을 기준으로 그룹화하여 그룹별로 결과를 반환하는 함수

### 집계함수 종료

| 함수 | 설명 |
| --- | --- |
| COUNT(ALL 컬럼명) | 그룹 내 해당 컬럼이 NULL이 아닌 레코드 수 |
| COUNT(DISTINCT 컬럼명) | 중복을 제외한 레코드 수 |
| COUNT(*) | 전체 레코드 수 (NULL 포함) |
| SUM(DISTINCT / ALL 컬럼명) | 그룹 내 해당 컬럼 값의 합계 |
| AVG(DISTINCT / ALL 컬럼명) | 그룹 내 해당 컬럼 값의 평균 |
| MAX(DISTINCT / ALL 컬럼명) | 그룹 내 해당 컬럼 값 중 최대값 |
| MIN(DISTINCT / ALL 컬럼명) | 그룹 내 해당 컬럼 값 중 최소값 |
